# בירה על המלצר - PWA

## העלאה ל-GitHub Pages
1. צור repository חדש ב-GitHub (ציבורי).
2. העלה אליו את **כל** הקבצים והתיקיות מכאן (index.html, sw.js, manifest.webmanifest, favicon.ico, .nojekyll, תיקיית icons).
3. Settings ← Pages ← Source: "Deploy from a branch" ← Branch: main, תיקייה: / (root) ← Save.
4. אחרי דקה-שתיים הכתובת תהיה: `https://<שם-משתמש>.github.io/<שם-הריפו>/`
5. פתח בטלפון בדפדפן (Chrome באנדרואיד, Safari באייפון):
   - אנדרואיד: תפריט ← "התקן אפליקציה" / "הוסף למסך הבית".
   - אייפון: כפתור שיתוף ← "הוסף למסך הבית".
6. אחרי הביקור הראשון (עם אינטרנט) המשחק עובד גם בלי חיבור.

## עדכון גרסה
1. החלף את `index.html` בגרסה החדשה.
2. ב-`sw.js` שנה את `VERSION` (למשל מ-1.0.0 ל-1.0.1).
3. עשה commit ו-push.
4. מי שפותח את המשחק עם אינטרנט יראה הודעה "🔄 יצאה גרסה חדשה" עם כפתור "עדכן עכשיו".
   אם לא תלחץ, העדכון יחול בפעם הבאה שתסגור ותפתח את המשחק.

## בדיקה מקומית
Service Worker לא עובד מ-`file://`. הרץ בתיקייה: `python3 -m http.server 8080` ופתח `http://localhost:8080`.

## הערות
- ההקלטות, השיאים וההתקדמות נשמרים בדפדפן (localStorage) ולא נמחקים בעדכון.
- המיקרופון (אולפן הקולות) עובד כי GitHub Pages הוא https.
